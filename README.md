# Website UI Research Skill

A reusable Codex skill for auditing and improving website UX, visual design, accessibility, performance, and conversion.

## Use

Invoke it in Codex with:

`$website-ui-research Audit this website: https://example.com`

For best results, provide the website URL, target users, primary business goal, and known problems.

## Contents

- `skills/website-ui-research/SKILL.md` — skill instructions
- `skills/website-ui-research/agents/openai.yaml` — Codex UI metadata

The skill covers research methods, tool selection, metrics, prioritization, production-quality checks, and validation.
